**Windows taskbar / desktop icon looked like a solid blue tile while ``dss_tools.ico`` in the repo looked correct.** Causes: (1) PyInstaller embedded an ICO that only contained a tiny frame because Pillow wrote the smallest size first; (2) desktop shortcuts pointed at ``dss_tools.ico`` while the taskbar used the **embedded** icon in ``DSSTools.exe``, so the two could disagree; (3) Windows icon cache. **Mitigations shipped:** ``tools/ensure_dss_tools_ico.py`` builds square multi-size ICO with 256×256 first; CI/Inno shortcuts use ``DSSTools.exe`` for ``IconFilename``; release workflow requires ``DSS-Tools Icon.png`` and regenerates ``dss_tools.ico`` from it only (no placeholder). Rebuild the installer after these changes; restart or refresh icon cache only if a ghost image persists.
